# 발표자료

부산신항 환적 컨테이너가 어디에서 오래 머무는지 살펴보고, 연결선 일정 조정과 선석 공유를 함께 검토한 발표자료입니다.

[발표 PPT 다운로드](busan_itt_presentation.pptx)

총 19장으로, 분석 결과와 시뮬레이션 비교, 현장 적용 전 확인할 점을 담았습니다. 슬라이드 노트에는 발표할 때 참고할 설명과 자료 출처를 넣었습니다.

## 발표 전 확인

- 사용 글꼴은 **Noto Sans KR**입니다. 발표용 PC에도 같은 글꼴이 있는지 확인해 주세요.
- 제시한 개선 수치는 **2025년 자료를 이용한 모형 결과**입니다. 실제 도입 성과와 구분해서 설명해 주세요.
- 공정 분석과 시뮬레이션은 체류시간의 측정 구간이 다릅니다. 수치의 출처와 구분 기준은 [검증 메모](검증메모.md)에 정리했습니다.
